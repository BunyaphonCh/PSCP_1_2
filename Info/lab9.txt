Lab 09.01 - coinExchangeV2

นื่องบางเทสเคสอาจจะได้คำตอบของจำนวนเหรียญทั้งหมดที่ต้องใช้เท่ากัน แต่ว่าจำนวนของเหรียญแต่ละประเภทไม่เท่ากัน จึงต้องเรียงเหรียญที่มีมูลค่ามากสุดไปน้อยสุดก่อน จึงจะทราบได้ว่าถ้าต้องใช้เหรียญชนิดนี้ ต้องใช้น้อยที่สุดเท่าไร และใช้แนวคิดแบบ Dynamic Programming ที่นำผลลัพธ์ย่อยมาใช้หาคำตอบในผลลัพธ์ที่ใหญ่กว่า

Input Specification
2 บรรทัด

บรรทัดแรกเป็นจำนวนเงินที่ต้องการแลกเหรียญ เป้นจำนวนเต็มบวก
บรรทัดที่ 2 เป็นข้อมูล Dictionary ที่เก็บจำนวนเหรียญที่มีมูลค่าต่าง ๆ
Output Specification
มี อย่างน้อย 2 บรรทัด บรรทัดแรกแสดงคำว่า Amount: {จำนวนเงินที่ต้องการแลก}
บรรทัดต่อ ๆ ไปให้เป้นไปตามเงื่อนไข ดังนี้

ถ้าไม่สามารถแลกเป็นเงินตามที่ต้องการได้พอดีให้แสดงผลว่า Can not exchange.
ถ้าสามารถแลกได้พอดี ให้แสดงผลจำนวนเหรียญแต่ละประเภทที่ต้องใช้แลก เรียงจากเหรียญที่มีมูลค่ามากสุดไปน้อยสุด

input :
105
{"13": 10, "7": 10, "3": 10, "2": 10}

output :
Amount: 105
Coin exchange result:
  13 baht = 7 coins
  7 baht = 2 coins
  3 baht = 0 coins
  2 baht = 0 coins
Number of coins: 9

input :
155
{"10": 10, "5": 10, "1": 10}

output :
Amount: 155
Coin exchange result:
  10 baht = 10 coins
  5 baht = 10 coins
  1 baht = 5 coins
Number of coins: 25

input :
123
{"9": 6, "18": 6}

output :
Amount: 123
Can not exchange.

Lab 09.02 - KnapsackV2

Input Specification
2 บรรทัด

บรรทัดแรก เป็นข้อมูลประเภท List ซึ่งภายใน List จะมีข้อมูลของสินค้าแต่ละชิ้น ประกอบไปด้วยชื่อสินค้า ราคา และน้ำหนัก
บรรทัดที่ 2 เป็นน้ำหนักที่กระเป๋าสามารถรองรับได้ เป็นจำนวนเต็ม
Output Specification
มีได้หลายบรรทัด เป็นรายการสินค้าที่เลือกหยิบลงกระเป๋า ถ้ามีหลายชิ้นให้เรียงตามตัวอักษร A - Z

input :
[["streo", 4300, 3], ["laptop", 2660, 2], ["guitar", 1600, 1]]
3

output :
Total: 4300
streo -> 3 kg -> 4300 THB

input :
[["streo", 3000, 3], ["laptop", 4000, 2], ["guitar", 1500, 2], ["watch", 8000, 1],["tablet", 7000, 4], ["perfume", 6000, 2]]
7

output :
Total: 21000
perfume -> 2 kg -> 6000 THB
tablet -> 4 kg -> 7000 THB
watch -> 1 kg -> 8000 THB

Lab 09.03 - Longest Common Substring

Input Specification
2 บรรทัด เป็น สตริง ที่ประกอบไปด้วยตัวอักษร A - Z ซึ่งมีความยาวของสตริงเท่ากัน

Output Specification
1 หรือ 2 บรรทัด

ถ้าไม่มีส่วนใดของสตริงที่เหมือนกันเลย ให้แสดงผลว่า No common substring.
ถ้ามีส่วนของสตริงที่เหมือนกัน ให้แสดงผลสตริงที่ยาวที่สุด ตามด้วยความยาวของสตริงตัวนั้น ถ้ามีหลายตัว ให้ตอบเฉพาะตัวแรกที่พบ โดยยึดจาก สตริงตัวแรกเป็นหลัก

input :
ABBSABBCSBBASBBCBS
KDKSDJBBCSBAAABBCB

output :
BBCSB
5

input :
AAAAAAA
ZZZZZZZ

output :
No common substring.
