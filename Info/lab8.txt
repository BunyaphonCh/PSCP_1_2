Labs 08.01 - Coin Exchange

Timeout: 1 second
Memory Limit: 32000 bytes
นายเพชรขึ้นรถไฟจากสถานีหัวหมากมาเรียนทุกวันซึ่งราคาตั๋วรถไฟจากสถานีหัวหมากมายังสถานีหัวตะเข้นั้นราคา 3 บาท แต่ว่านายเพชรนั้นยื่นแบงค์ 20 บาทให้พี่พนักงานขายตั๋ว ด้วยความที่เป็นชั่วโมงเร่งด่วนพี่พนักงานขายตั๋วจึงได้เปิดสกิลพิเศษในการใช้ Greedy Algorithms ในทอนเงินให้กับนายเพชรโดยใช้จำนวนเหรียญน้อยสุดเพื่อความรวดเร็ว

นายเพชรนั้นตกใจมากที่เห็นพี่พนักงานขายตั๋วนั้นทอนเงินให้ตนด้วยความรวดเร็ว นายเพชรจึงไปรวมทีมกับนายดรีมเพื่อที่จะสร้างฟังก์ชัน coinExchange(amount, coinList) เพื่อทำการคำนวณการทอนเหรียญสำหรับเงินจำนวน amount บาทขึ้นมา

ทั้งคู่ได้สร้างฟังก์ชัน coinExchange(amount, coins) เพื่อทำการคำนวณการทอนเหรียญสำหรับเงินจำนวน amount บาท

ให้ใช้แนวคิดการแก้ปัญหาด้วย Greedy algorithm ซึ่งพยายามทอนเงินโดยใช้จำนวนเหรียญน้อยๆ
กำหนดให้เหรียญมีมูลค่าต่างๆ กัน ได้แก่ เหรียญ 10 บาท, 5 บาท, 2 บาท และ 1 บาท ตามลำดับ และอาจมีจำนวนเหรียญที่แตกต่างกันได้
amount เป็นเลขจำนวนเต็ม แทนจำนวนเงินบาทที่ต้องการแลกเหรียญ
coins เป็นข้อมูลประเภท Dict ที่เก็บจำนวนเหรียญที่มีมูลค่าต่างๆ เช่น
coins = {10: 50, 5: 60, 2: 70, 1: 100}
หมายถึง มีเหรียญ 10 บาท, 5 บาท, 2 บาท และ 1 บาท จำนวน 50, 60, 70 และ 100 เหรียญ ตามลำดับ
ฟังก์ชันจะแสดงจำนวนเหรียญของเหรียญมูลค่าต่างๆ ตามที่โจทย์กำหนด
กรณีที่จำนวนเหรียญไม่เพียงพอกับเงินที่ต้องการแลก โปรแกรมจะแสดงข้อความ "Coins are not enough"

ในการโหลดข้อมูลเพื่อให้ข้อมูล Dictionary มีรูปแบบ dict<int, int> นายเพชรจะใช้ฟังก์ขันด้านล่างในการแปลงข้อมูล

Labs 08.02 - Item Class

Timeout: 1 second
Memory Limit: 32000 bytes
สกาวเดือนได้ทำการแจกโบนัสให้พนักงานทุกคนที่ทำงานในบริษัทแล้วแต่แอพโดยรอบนี้สกาวเดือนนั้นไม่ได้เตรียมเงินใส่ซองปิดผนึกไว้จำนวน 5 ซอง แต่ว่าสกาวเดือนนั้นเตรียมสิ่งของต่างๆ ที่เธอได้ซื้อมาจากห้างสรรพสินค้าเพื่อที่จะให้พนักงานในบริษัทแล้วแต่แอพเล่นเกมส์หยิบของให้ได้มากที่สุดใน 10 วินาทีและสามารถบรรจุของที่หยิบได้ลงในกระเป๋าเพียงใบเดียวเท่านั้น

นายปิ๊ก (หนึ่งในทีมนักพัฒนาแล้วแต่แอพ) ได้ทราบข่าวเรื่องที่สกาวเดือนจะแจกโบนัส นายปิ๊กเลยได้ไปบอกส้มฉุนกับท่านโอห์ม ทั้ง 3 คนเลยได้ได้ตกลงกันว่าจะเลือกหยิบสินค้าโดยให้ได้มูลค่ารวมมากที่สุดและหยิบแบบใช้ Greedy Algorithms

ส้มฉุนเลยไปติดต่อกับพี่โฟล์คฝ่ายพัสดุเพื่อที่จะให้พี่โฟล์คไปสืบหารายชื่อของสิ่งของต่างๆ ที่คุณสกาวเดือนได้ซื้อมา เมื่อพี่โฟล์คไปสืบมาได้พี่แกจะส่งข้อมูลกลับมาเป็น list ที่เก็บอ็อบเจ็กสิ่งของที่สกาวเดือนไปซื้อมาโดยพี่โฟล์คได้ออกแบบคลาส Item ขึ้นมาในการเก็บข้อมูลของสินค้าแต่ละตัวซึ่งภายในคลาสจะเก็บข้อมูลชื่อ, ราคาและน้ำหนักของสินค้าประเภทนั้นๆ ซึ่งคลาสจะมีลักษณะดังนี้

Attributes (คุณลักษณะ) ได้แก่
name คือชื่อของสินค้า
price คือราคาของสินค้า (จำนวนจริง)
weight คือน้ำหนักของสินค้า (จำนวนเด็ม)
Methods (เมธอด) ได้แก่
.get_name() ทำหน้าที่ส่งค่า name
.get_price() ทำหน้าที่ส่งค่า price
.get_weight() ทำหน้าที่ส่งค่า weight
.get_cost() คำนวณหาค่าที่ใช้ในการเลือกสินค้าตามแนวคิด Greedy algorithm
เช่น เลือกจากราคาของสินค้าต่อน้ำหนัก เป็นต้น

ใช้โค้ดด้านล่างในการเช็คผลลัพธ์

Labs 08.03 - Knapsack

Timeout: 1 second
Memory Limit: 32000 bytes
เมื่อพี่โฟล์คสร้างคลาส Item เสร็จก็ได้ทำการเพิ่มข้อมูลของสินค้าที่สกาวเดือนได้ซื้อมาลงไปในคลาส Item และเก็บข้อมูลทั้งหมดไว้ในลิสต์เพื่อที่จะเอาไว้ส่งต่อให้ส้มฉุน

ต่อมาจะเป็นหน้าที่ขของนายปิ๊กและเพื่อนๆ ของเขาที่จะรับผิดชอบในการที่จะเขียนฟังก์ชันที่จะคำนวณว่านายปิ๊กควรจะหยิบสินค้าชนิดไหนเป็นอันดับแรกเพื่อให้ได้มูลค่ารวมของสินค้าในกระเป๋ามากที่สุด

นายปิ๊กจะสร้างฟังก์ชัน knapsack(amount, itemList) เพื่อทำการหยิบของจาก itemList ใส่ในกระเป๋าที่สามารถรองรับน้ำหนักได้ amount กก.
ให้ใช้แนวคิดการแก้ปัญหาด้วย Greedy algorithm เพื่อพยายามหยิบของให้ได้มูลค่ารวมมากที่สุด
กำหนดให้สินค้ามีมูลค่าและน้ำหนักที่แตกต่างกัน เช่น กีต้าร์ ราคา 5,500 บาท มีน้ำหนัก 3 กก. เป็นต้น
amount เป็นเลขจำนวนเต็ม แทนน้ำหนักที่กระเป๋าสามารถรองรับได้
itemList เป็นลิสต์ที่เก็บอ็อบเจ็กสินค้าที่อยู่ในร้าน โดยอ็อบเจ็กสินค้าจะมี attribute ต่างๆ ได้แก่ ชื่อสินค้า (name), ราคาสินค้า (price) และน้ำหนักสินค้า (weight)
ฟังก์ชันจะแสดง รายการสินค้าที่หยิบใส่ในกระเป๋า และมูลค่าสินค้ารวม
ถ้าหากว่าค่าที่ใช้ในการเลือกสินค้าเท่ากันให้เลือกสมาชิกตัวแรกสุดจากข้อมูลที่รับเข้ามาก่อน
เมื่อนายปิ๊กสร้างฟังก์ชันเสร็จ นายปิ๊กจะเอาโค้ดฟังก์ชันที่นายปิ๊กสร้างขึ้นมาแล้วเอาไปให้ท่านโอห์มตรวจผ่านโค้ดด้านล่าง

def main():
  import json
  items = []
  num_items = int(input())
  while num_items != 0:
    item_in = json.loads(input())
    items.append(Item(item_in['name'], item_in['price'], item_in['weight']))
    num_items = num_items - 1
    knapsack_capacity = float(input())
    knapsack(items, knapsack_capacity)
main()

แอพพลิเคชั่นสั่งอาหารบนโทรศัพท์มือถือตัวใหม่มีชื่อว่า "แล้วแต่แอพ" ซึ่งในแต่ละครั้งที่ใช้งาน แอพพลิเคชัน นี้จะสุ่มเลือกเมนูอาหารมาให้ผู้ใช้งานเพียง 1 อย่างโดยอัตโนมัติ และผู้ใช้งานจะต้องสั่งเมนูอาหารที่แอพพลิเคชันนี้สุ่มเลือกมาให้เท่านั้น แอพพลิเคชันจะสุ่มเลือกเมนูอาหารแต่ละอย่างด้วยความน่าจะเป็น

สกาวเดือนต้องการโฆษณาแอพพลิเคชั่นสั่งอาหารแล้วแต่แอพในประเทศสหรัฐอเมริกาที่ West Coast ตอนกลางเนื่องจากว่ามีคนไทยอยู่เยอะมาก (ราวๆ 200,000++ คน) ซึ่งมีนายฟลุ๊คกับเซิณทำงานอยู่ที่ฝ่ายการตลาดและโฆษณาของบริษัทแล้วแต่แอพจำกัด สกาวเดือนเลยได้ไปบอก 2 คนนี้ให้ทั้งคู่กระจายข่าวสารและโฆษณาแล้วแต่แอพไปทางช่องวิทยุต่างๆ โดยมีเงื่อนไขคือว่าต้องใช้จำนวนสถานทีวิทยุที่น้อยที่สุดเพื่อประหยัดค่าใช้จ่าย

นายฟลุ๊คเลยได้ตกลงกับนายเซิณว่าจะเลือกสถานีวิทยุที่ครอบครุมเมืองใน California มากที่สุดเช่นสมมุติมีสถานีวิทยุ 3 สถานี และมีเมืองทั้งหมดดังนี้ {San Franscisco, San Jose, Sacramento, Fresno, Bakersfield}

สถานี B ครอบครุมเมือง San Franscisco, San Jose, Sacramento

สถานี C ครอบครุมเมือง Fresno, Bakersfield, San Jose
นายฟลุ๊คจะต้องเลือกสถานี A และ B เพราะว่าสถานี A ครอบครุมเมืองเกือบทั้งหมดแต่ไม่ครอบครุมเมือง Reno, สถานี B ครอบครุมเมือง Reno นายฟลุ๊คจึงจะต้องเลือก 2 สถานีเพื่อให้ครอบครุมเมืองทุกเมืองที่นายฟลุ๊คต้องการจะโฆษณา
เมื่อฟลุ๊คกับเซิณคุยกันเสร็จ เซิณก็ได้ทำการสร้างฟังก์ชัน ฟังก์ชัน findStations(stations) เพื่อทำการเลือกสถานีวิทยุ จาก stationDict เพื่อทำการโฆษณาสินค้าของบริษัทให้ครอบคลุมทุกพื้นที่โดยรายละเอียดของฟังก์ชันมีดังนี้
​ให้ใช้แนวคิดการแก้ปัญหาด้วย Greedy algorithm เพื่อพยายามเลือกสถานีวิทยุให้น้อยที่สุดและครอบคลุมพื้นที่การโฆษณาทั้งหมด
stations เป็น Dictionary ที่มี key เป็นชื่อสถานีวิทยุ และมี value เป็นลิสต์ของพื้นที่ที่สถานีนั้นครอบคลุม เช่น

  }
