Lab 06.02 - ProbHash Hashing

Timeout: 1 second
Memory Limit: 32000 bytes

นายปิ๊ก (หนึ่งในทีมนักพัฒนาแล้วแต่แอพ) ต้องการจะเพิ่มฟีเจอร์ในการเก็บข้อมูลด้วยการ Hasing ให้กับนักศึกษาคณะ IT ที่มาใช้บริการสั่งอาหารผ่านแอพพลิเคชั่นสั่งอาหารบนโทรศัพท์มือถือตัวใหม่มีชื่อว่า "แล้วแต่แอพ"

เมื่อละอองดาวสร้างคลาส Student เสร็จ เธอได้ส่งโค้ดให้นายปิ๊กและไปทำการทดลองหาค่าเฉลี่ยของละอองฝุ่นในแต่ละวันต่อ นายปิ๊กรู้สึกดีใจมากที่ได้คลาส Student จากละอองดาว แต่ว่าฟีเจอร์แล้วแต่แอพนี้ยังไม่เสร็จสมบูรณ์ ยังขาดคลาส ProbHash ที่ทำหน้าที่เป็น Hash Table

นายปิ๊กจึงไปร่วมมือกับส้มฉุนเพื่อสร้างคลาส ProbHash ขึ้นมาโดยคลาสนี้จะมี attribute เป็น
ตารางแฮช (hash_table): เป็นลิสต์ที่เก็บข้อมูลออบเจ็กต์นักเรียน (Student) ได้ n คน
ขนาดข้อมูล (size): ของตารางแฮช (ขนาดทั้งหมด ไม่ใช่ขนาดของข้อมูลที่ถูกเก็บไว้ในลิสต์)
และสามารถทำ Operation ต่างๆ ได้ ดังนี้
hash(key): คืนค่าผลลัพธ์การ hash แบบ Modulo-division  
rehash(hkey): คืนค่าผลลัพธ์การ rehash
กรณีที่มีการชนกันของข้อมูล โดยให้แก้ปัญหาการชนกันด้วยวิธี Linear Probing
insert_data(student): ทำการเพิ่มข้อมูลออบเจ็กต์ student ตามตำแหน่งที่ได้จากการ hash หรือ rehash ได้
เมื่อเพิ่มข้อมูลสำเร็จ ให้แสดงข้อความว่า
Insert at index
กรณีที่ข้อมูลเต็ม ให้แสดงข้อความว่า
The list is full.  could not be inserted.
search_data(std_id): คืนค่าออบเจ็กต์ student ที่มีรหัสนักศึกษาเป็น std_id
พร้อมทั้งแสดงข้อความให้เห็นว่าพบข้อมูลของ std_id ที่ตำแหน่ง (index) ไหน
Found at index
กรณีไม่เจอข้อมูล ให้แสดงข้อความว่า
 does not exist.
นายปิ๊กและส้มฉุนทำงานเสร็จ ทั้งสองคนได้เรียกหัวหน้างานชื่อว่าท่านโอห์มมาตรวจงานที่ทั้ง 2 คนนั้นทำไว้ โดยที่ท่านโอห์มได้ทำการเอาโค้ดที่ทั้ง 2 คนได้สร้างขึ้นมา นำมาตรวจสอบความถูกต้องผ่านโค้ดด้านล่าง

def main():
    import json
    size = int(input())
    hashtable = ProbHash(size)
    while True:
        finish = input()
        if finish == "Done":
            break
        condition, data = finish.split(" = ")
        if condition == "I":
            std_in = json.loads(data)
            std = Student(std_in["ID"], std_in["Name"], std_in["GPA"])
            hashtable.insert_data(std)
        elif condition == "S":
            print("------")
            student = hashtable.search_data(int(data))
            if student is not None:
                student.print_details()
            print("------")
        else:
            print("Invalid Condition!")
main()
