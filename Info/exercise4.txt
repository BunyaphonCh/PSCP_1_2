ในโลกแห่งหนึ่ง มีเมืองที่มีชื่อว่า “ละอองดาวซิตี้” เป็นเมืองที่มีคนรักในการเขียนโปรแกรมและแก้ปัญหา ในเมืองนี้มีทีมนักพัฒนาโปรแกรมที่มีชื่อว่า “League Of Binary Search Tree” ซึ่งประกอบด้วย 5 สมาชิก คือ คุณดิด, คุณน้ำมนต์, คุณฟลุ๊ค, คุณเฟิร์สและคุณข้าว ทีมนี้มีความสามารถในการสร้างและจัดการกับต้นไม้ Binary Search Tree ที่มีความซับซ้อนสูง

วันหนึ่ง คุณดิดได้ทำการทดลองสุ่มตัวเลขขึ้นมา ในขณะเดียวกันคุณน้ำมนต์ก็ได้ทำการทดลองสร้างต้นไม้ Binary Search Tree ขึ้นมาเหมือนกัน ฟลุ๊คเดินมาเห็น ฟลุ๊คเลยอยากรู้ว่าตัวเลขที่คุณดิดสุ่มขึ้นมานั้น มีโอกาสและความน่าจะเป็นเท่าไรในการที่ตัวเลขนั้นจะไปอยู่ในต้นไม้ของคุณน้ำมนต์

ฟลุ๊คเลยเดินไปบอกเฟิร์สให้เฟิร์สเขียนเมธอด isExist ขึ้นมาเพื่อตรวจสอบว่ามีตัวเลขที่คุณดิดสุ่มขึ้นมาในต้นไม้ Binary Search Tree ของคุณน้ำมนต์หรือเปล่า และหาความน่าจะเป็นของแต่ละตัวเลขด้วย

เฟิร์สเห็นว่าเป็นโจทย์ที่น่าสนใจ แต่ก็ไม่ง่าย เฟิร์สเลยเริ่มเขียนโค้ดขึ้นมา

Input Specification
≥1 บรรทัด
รับข้อมูลจนกว่าจะเจอคำว่า "Done"
และตัวเลขของคุณดิสที่คุณดิสทำการทดลองสุ่มขึ้นมา

Output Specification
1 บรรทัด
ถ้าเป็นจริง ให้แสดงผลลัพธ์ว่า True
ถ้าไม่ ให้แสดงผลลัพธ์ว่า False

I: 13

True

I: 13

True

input :
I: 14

คุณเฟิร์สจากทีม League Of Binary Search Tree เป็นนักพัฒนาโปรแกรมที่มีความเชี่ยวชาญในการจัดการกับต้นไม้ Binary Search Tree ซึ่งเป็นโครงสร้างข้อมูลที่มีคุณสมบัติว่า โหนดซ้ายของโหนดใด ๆ จะมีค่าน้อยกว่าค่าของโหนดนั้น และโหนดขวาจะมีค่ามากกว่าค่าของโหนดนั้น คุณเฟิร์สได้สร้างเมธอด isExist ที่สามารถตรวจสอบว่ามีข้อมูลที่กำหนดให้อยู่ในต้นไม้หรือไม่ และคืนค่าเป็น True หรือ False ตามผลลัพธ์

คุณเฟิร์สได้รับการชื่นชมจากผู้คนมากมายและทีม BST Echo ซึ่งเป็นทีมนักพัฒนาโปรแกรมที่ชื่นชอบการเขียนโปรแกรมเกี่ยวกับต้นไม้ Binary Search Tree ทีมนี้ประกอบด้วย 5 สมาชิก คือ นายซัน, นายต้นน้ำ, นายคิว, นายมาร์คและนายปั้น ทีมนี้ต้องการพัฒนาโปรแกรมของคุณเฟิร์สให้มีความสามารถมากขึ้น ดังนั้น นายต้นน้ำได้ขอโค้ดจากคุณเฟิร์ส เพื่อนำไปใช้ในการพัฒนาต่อ

เมื่อได้รับโค้ด, ทีม BST Echo ได้แบ่งงานให้แต่ละสมาชิกดังนี้:
นายคิว: ทดลองสร้างต้นไม้ Binary Search Tree แบบสุ่ม โดยใช้เมธอด insert ที่คุณเฟิร์สเขียนขึ้นมา
นายมาร์คและนายซัน: ทดลองสุ่มข้อมูลตัวเลขภายในต้นไม้และกำหนดค่าตัวแปรสุ่ม (Random Variable)
นายปั้นและนายต้นน้ำ: ร่วมกันพัฒนาโปรแกรมของคุณเฟิร์สต่อยอด
นายต้นน้ำได้เสนอไอเดียว่า ถ้าเราสามารถหาความสูงของต้นไม้ Binary Search Tree ที่คิวสร้างขึ้นมาได้ นั้นจะเป็นสิ่งที่น่าทึ่งมาก เพราะความสูงของต้นไม้มีผลต่อประสิทธิภาพของการค้นหา, เพิ่ม, และลบข้อมูลในต้นไม้ ดังนั้น, นายปั้นและนายต้นน้ำจะร่วมกันเขียนโปรแกรมเพื่อหาความสูงของต้นไม้ Binary Search Tree ขึ้นมา

Input Specification
≥1 บรรทัด
รับข้อมูลจนกว่าจะเจอคำว่า "Done"

Output Specification
1 บรรทัด
ความสูงของต้นไม้

input :
I: 18
I: 11
I: 2
I: 19
I: 1
I: 10
Done

output :
4

input :
I: 14
I: 23
I: 7
I: 10
I: 33
